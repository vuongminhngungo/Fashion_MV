BÁO CÁO DỰ ÁN: FashionMN

Phiên bản báo cáo: 1.0 · Mục tiêu: Mô tả sản phẩm, cách thực hiện, và kết quả triển khai
E-commerce Fashion Web

1) Mô tả sản phẩm

FashionMN là dự án website thương mại điện tử thời trang hiện đại, xây dựng theo định hướng UI marketplace (Shopee-style), tối ưu trải nghiệm mobile-first và tốc độ tương tác.

Chức năng chính

  • Trang chủ với banner lớn, Flash Sale, danh mục nổi bật, sản phẩm nổi bật, hàng mới.
  • Trang sản phẩm có lọc/sắp xếp/phân trang theo URL.
  • Trang chi tiết sản phẩm có chọn màu, size, số lượng, thêm giỏ hàng/yêu thích.
  • Giỏ hàng, mã giảm giá mock (FASHION10), checkout đa bước.
  • Wishlist, Orders mock, Login/Register/Forgot Password (UI + validation).
  • Search debounce 300ms, API REST nội bộ qua Next.js Route Handlers.

Công nghệ

  • Next.js 15 (App Router) + TypeScript strict
  • Tailwind CSS v4
  • Framer Motion cho animation/micro-interaction
  • TanStack Query cho fetch/cache
  • Zustand + persist cho cart/wishlist
  • Prisma + PostgreSQL cho dữ liệu sản phẩm
  • react-hook-form + zod cho validation form

2) Cách thực hiện

2.1 Thiết kế kiến trúc & cấu trúc dự án

  • Chuẩn hóa cấu trúc thư mục theo App Router và module hóa theo feature.
  • Tách rõ app/, components/, lib/, store/, hooks/, prisma/.

2.2 Thiết kế dữ liệu

  • Model Product gồm đầy đủ thông tin e-commerce: giá, giá gốc, màu, size, tồn kho, rating, flags sale/featured/new.
  • Seed 24 sản phẩm (8 clothing, 8 shoes, 8 bags).
  • Tạo thêm file SQL mẫu import thủ công: prisma/sample-data.sql.

2.3 API và dữ liệu fallback

  • API: /api/products, /api/products/[slug], /api/search.
  • Fallback mock data khi DB chưa sẵn sàng để đảm bảo build không bị chặn.

2.4 Nâng cấp UI/Animation chuẩn Shopee-style

  • Header gradient marketplace + thanh search nổi bật + quick links.
  • Card sản phẩm dày thông tin, CTA rõ ràng, animation hover mượt.
  • Page transition, section reveal animation, countdown animation.
  • Đồng bộ visual toàn bộ trang: Home, Products, Detail, Cart, Checkout, Auth, Wishlist, Orders, Search.

2.5 CI thủ công và phát hành

  • Kiểm tra chất lượng bằng npm run typecheck và npm run build.
  • Commit + push đầy đủ lên GitHub theo từng mốc hoàn thành.

3) Kết quả đạt được

  • Đã hoàn thiện đầy đủ flow e-commerce từ khám phá sản phẩm đến đặt hàng.
  • Đã nâng cấp giao diện và animation theo phong cách marketplace hiện đại.
  • Đã kết nối/kiểm thử dữ liệu PostgreSQL thành công (24 sản phẩm).
  • Đã có file SQL mẫu để import dữ liệu khi cần.
  • Đã push source code hoàn chỉnh lên GitHub.

Chỉ số kỹ thuật kiểm thử

  • typecheck: Pass
  • production build: Pass
  • Route build thành công cho toàn bộ trang chính

4) Hướng dẫn sử dụng nhanh

  1. Cài dependencies: npm install
  2. Cấu hình .env với DATABASE_URL
  3. Import dữ liệu bằng prisma/sample-data.sql hoặc seed script
  4. Chạy dev: npm run dev
  5. Build production: npm run build

5) Kết luận

Dự án FashionMN đã đạt mục tiêu về mặt tính năng, tính thẩm mỹ UI, animation, tính nhất quán dữ liệu và khả năng triển khai. Hệ thống sẵn sàng cho giai đoạn mở rộng tiếp theo như thanh toán thực, quản trị sản phẩm, và tối ưu SEO/analytics.
